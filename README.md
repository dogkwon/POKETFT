🕹️ 사용 방법 (Usage Manual)
앱 설치 및 권한 허용이 끝났다면, 포켓몬 대전 게임(에뮬레이터, 닌텐도 스위치 캡처 보드 스트리밍 앱 등)을 실행한 뒤 아래 프로세스로 계산기를 조작합니다.
1. 오버레이 온/오프 제어최초 앱 메인 화면에서 오버레이 시작 버튼을 누르면 화면 구석에 아주 작은 '플로팅 버블 버튼'이 생성됩니다.게임 도중 계산이 필요할 때 이 버블을 터치하면 화면을 가로로 꽉 채우는 반투명 계산 보드(전체화면 오버레이)가 펼쳐집니다.
2. 왼쪽 상단의 [X] 버튼을 누르면 다시 버블 형태로 최소화되어 게임 화면을 방해하지 않습니다.
3. 실전 대전 데이터 세팅 (터치 최소화 프로세스)포켓몬 검색: 좌측(내 포켓몬) 및 우측(상대 포켓몬) 검색창에 이름을 입력합니다.
(예: 메가 입력 시 메가리자몽X 등 자동완성 리스트 팝업 $\rightarrow$ 선택 시 종족값 즉시 로드)기술 및 도구 선택: 로드된 데이터셋을 기반으로 활성화된 드롭다운 메뉴에서 사용할 기술과 지니고 있는 도구(예: 목탄, 금속코트)를 터치하여 세팅합니다.스탯 및 랭크 세부 조작

(개체값은 6V 자동 고정 계산)[📊 Rank] 버튼 터치: 현재 필드에서 변화한 공격/방어 등의 랭크 상태(-6 ~ +6)를 화살표로 조작합니다.

1. 기존 웹 계산기의 치명적인 한계 극복 (가장 큰 이유)
기존의 스마트누오나 토오 같은 좋은 웹 계산기들이 있지만, 스마트폰 하나로 게임을 하면서 계산을 하려면 다음과 같은 지옥의 동선이 발생합니다.
화면 전환 렉: 포켓몬 게임을 하다가 홈 화면으로 나가서 브라우저를 켜고 계산기를 확인하는 순간, 앱이 백그라운드에서 리프레시되거나 게임 화면으로 돌아올 때 렉이 유발됩니다.
시간 제한 압박: 포켓몬 랭크 배틀은 매 턴 선택 시간이 제한되어 있습니다. 그 촉박한 시간 동안 검색창 누르고, 자판 뜨면 타이핑하고, 기술 고르고 이러다 시간 초과로 기술이 멋대로 나가는 대참사가 비일비재합니다.
이 앱의 해결책: 게임 화면 위에 상시 반투명하게 떠 있고, 타이핑 없이 오직 터치 몇 번(자동완성 및 +32/-32 버튼)으로 2~3초 만에 계산을 끝내기 때문에 턴 타임아웃 압박에서 완벽하게 해방됩니다.

3. 실전 배틀의 승률을 바꾸는 '쌍방향/환경 실시간 추적'
실전 배틀은 내가 때리는 것만 계산해서는 절대 이길 수 없습니다. "내가 저 녀석을 제비반환으로 잡을 수 있나?"와 동시에 "저 녀석의 파생 기술을 내가 버틸 수 있나?"를 동시에 봐야 합니다.
쌍방향 동시 표기: 화면 전환 없이 내가 줄 데미지와 받을 데미지가 한눈에 보입니다.
유동적인 환경 반영: 대전 중 쾌청이 깔리거나 일렉트릭필드가 깔렸을 때, 혹은 상대가 리플렉터를 깔았을 때 중앙의 드롭다운만 딸깍 바꾸면 양쪽 데미지가 실시간으로 재계산됩니다.



# ⚙️ 5분 완성 실행 가이드 (Android Studio 처음 쓰는 사람용)

안드로이드 스튜디오를 아예 처음 써보는 학생들도 쉽게 따라 할 수 있도록 한 단계씩 정리한 가이드입니다. 순서대로만 누르면 완벽하게 실행됩니다!

### Step 1. 개발 환경 준비하기
1. [안드로이드 스튜디오 공식 홈페이지](https://developer.android.com/studio)에 접속해 본인의 OS(Windows / Mac)에 맞는 버전을 다운로드하고 설치합니다.
2. 설치 과정 중 나오는 선택창은 모두 기본값(**Next** 및 **Finish**)을 누르면 됩니다.

### Step 2. 프로젝트 다운로드 및 열기
1. 이 깃허브 페이지 오른쪽 상단의 초록색 **`[Code]`** 버튼을 누른 뒤, **`[Download ZIP]`**을 클릭합니다.
2. 다운로드된 압축 파일을 바탕화면이나 찾기 쉬운 폴더에 해제합니다.
3. 안드로이드 스튜디오를 켜고, 첫 화면에서 **`[Open]`** (또는 `File` -> `Open`)을 누릅니다.
4. 방금 압축을 푼 프로젝트 폴더를 찾아 선택하고 **`[OK]`**를 누릅니다.
5. > ⚠️ **중요 (최초 동기화 대기):** 프로젝트가 처음 열리면 화면 우측 하단에 무언가 다운로드되는 게이지가 올라갑니다. 컴퓨터 성능에 따라 1~3분 정도 소요되니, 이 작업(**Gradle Sync**)이 끝날 때까지 아무것도 누르지 말고 완전히 대기해 주세요.

### Step 3. 필수 데이터 파일 위치 확인하기
앱이 정상적으로 포켓몬을 검색하려면 데이터 파일이 올바른 위치에 있어야 합니다.
1. 안드로이드 스튜디오 왼쪽 상단의 프로젝트 탐색기 창을 확인합니다.
2. `app` -> `src` -> `main` -> `assets` 폴더를 차례로 엽니다.
3. 이 폴더 안에 **`pokemon_db.json`**과 **`moves_db.json`** 파일이 정상적으로 들어있는지 눈으로 꼭 확인하세요! (없으면 실행 후 검색이 안 됩니다.)

### Step 4. 스마트폰 연결 및 실행하기 (2가지 방법 중 택 1)

#### 방법 A: 본인의 안드로이드 실제 스마트폰 사용 (추천, 갤럭시 등)
1. 스마트폰의 `설정` -> `휴대전화 정보` -> `소프트웨어 정보`로 이동합니다.
2. **`[빌드 번호]`**라는 항목을 연속으로 **7번** 빠르게 다다닥 누르면 "개발자 모드를 켰습니다"라는 안내가 뜹니다.
3. 뒤로 나가서 `설정` 맨 밑에 새로 생긴 **`[개발자 옵션]`**으로 들어갑니다.
4. 스크롤을 살짝 내려 **`[USB 디버깅]`** 항목을 켭니다.
5. 스마트폰을 데이터 케이블로 PC와 연결합니다. (폰 화면에 팝업이 뜨면 '허용' 클릭)
6. 안드로이드 스튜디오 상단 중앙을 보면 본인의 스마트폰 모델명(예: `Samsung SM-G998N`)이 자동으로 잡힌 것을 볼 수 있습니다.
7. 그 바로 오른쪽에 있는 초록색 재생 버튼(**`▶ (Run App)`**)을 누르면 폰에 앱이 설치됩니다!

#### 방법 B: 가상 스마트폰(에뮬레이터) 컴퓨터에 띄워서 사용
1. 안드로이드 스튜디오 우측 최상단 툴바에서 스마트폰 모양 아이콘인 **`[Device Manager]`**를 클릭합니다.
2. **`[Create Device]`** (또는 `+` 버튼)를 누릅니다.
3. 크기가 적당한 기기(예: `Pixel 7`)를 고르고 `Next`를 누릅니다.
4. 시스템 이미지 선택 창에서 최신 버전(예: `API 34` 또는 `UpsideDownCake`) 옆의 **`[Download]`**를 눌러 설치한 뒤 `Next` -> `Finish`를 누릅니다.
